# 運用ガイド（画面手順・トラブルシューティング）

ユーザーに操作を案内するとき、また構築完了時に「運用マニュアル.md」を生成するときの
下敷きにする。手順は2026年時点のUI。画面が変わっていたら実際の画面に合わせて案内し直すこと。

## Discord Webhook の作り方（5分・無料・無制限）

1. Discordで**サーバーを作成**（「+」→「サーバーを作成」→「自分だけ」でOK）
2. 通知用の**チャンネルを作成**（例: `#seo通知`。用途別に `#記事チェック` `#競合` と分けると見やすい）
3. チャンネルの**歯車アイコン（編集）**をクリック
4. **「連携サービス」→「ウェブフック」→「新しいウェブフック」**
5. **「ウェブフックURLをコピー」** → これが通知の宛先

注意事項として必ず伝える:
- Webhook URLは「知っている人は誰でもそのチャンネルに書き込める」パスワード相当。
  ネットに貼らない。漏れたらDiscord側で削除→作り直せば無効化できる。

## Search Console のCSVエクスポート（週次運用）

1. Search Console → 「検索パフォーマンス」
2. 期間を「過去7日間」に設定
3. 右上「エクスポート」→「CSVをダウンロード」（zipが落ちる）
4. zipを解凍 → **`クエリ.csv`（Queries.csv）** を `seo-report/取込/` に入れる
5. `レポート実行.command` をダブルクリック

補足: サチコのデータ反映は2〜3日遅れる。列の並びは
「上位のクエリ / クリック数 / 表示回数 / CTR / 掲載順位」を想定（スクリプトは
CTRの `%` 表記・小数表記の両方に対応済み）。

## GA4 のCSVエクスポート（週次運用）

1. GA4 → 「レポート」→「エンゲージメント」→「ページとスクリーン」
2. 右上の日付を「過去7日間」に設定
3. 右上の共有アイコン（↑）→「ファイルをダウンロード」→「CSVをダウンロード」
4. CSVを `ga-report/取込/` に入れる → `レポート実行.command` をダブルクリック

補足:
- GA4のCSVは先頭に `#` の注釈行が数行入る。スクリプトは自動で読み飛ばす
- CROアラートには「平均エンゲージメント時間」「キーイベント」列が必要
  （「ページとスクリーン」には標準で含まれる）
- CV判定の精度を上げるには、GA4側で問い合わせ・購入等を「キーイベント」に設定しておく

## Gemini APIキーの取得（5分・無料・カード登録不要）

1. Google AI Studio → https://aistudio.google.com/ にGoogleアカウントでログイン
2. 「Get API key / APIキーを取得」→ 規約同意（初回のみ）
3. 「APIキーを作成」（プロジェクトは「新しいプロジェクトで作成」でOK）
4. 表示されたキーをコピー

伝えるべきこと:
- 課金設定をしない限り自動請求はない。無料枠を超えると止まるだけ
- スクリプトには無料枠超過を検知すると🚨課金アラートをDiscordに送る仕組みが入っている
- キーもパスワード相当。取り扱い注意。AI Studioからいつでも削除・再発行できる
- キーの形式は `AIza...` 形式と `AQ....` 形式の両方が存在する。どちらも有効。
  受け取ったら models エンドポイント（`/v1beta/models?key=...`）で疎通確認すると確実

## 記事リスト.csv の形式（article-check用）

```csv
URL,対策キーワード
https://example.com/article-1,主要KW サブKW
https://example.com/article-2,別のKW
```

- 1列目: 記事のフルURL（http始まり以外の行はヘッダーとして無視される）
- 2列目: 対策キーワード（空でも動く。スペース/／区切りで複数語OK。
  最初の語が「主要KW」としてタイトル/H1チェックに使われる）
- ユーザーがリストを持っていない場合は、本人のサイトのsitemap.xmlからURL一覧を
  抽出してCSV雛形を生成してあげる（competitor_watch.py の collect_urls と同じロジックが使える）
- Numbers/Excelで管理している場合: Numbersは
  `osascript` で `export theDoc to (POSIX file "...") as CSV` により変換できる。
  列の向き（URLとKWが逆）や相対パス（ドメイン補完が必要）に注意して整形する

## 競合リスト（competitors.txt）の運用

競合サイトは `competitor-watch/competitors.txt` に **1行1URL** で書く（コードは触らない）。
`#` で始まる行はコメント。

**URLを足したら、必ず疎通チェックする:**
- `competitor-watch/競合疎通チェック.command` をダブルクリック（または
  `python3 competitor_watch.py check`）
- 各サイトが「✅ ... : N URL」と出ればOK。「❌ 0 URL」は sitemap が無く監視できないので、
  そのサイトは外して別の競合に差し替える
- 一般的なメディアでも標準の `sitemap.xml` を出していないサイトは多い。登録前チェックは省略しない

## Macでの初回実行（Gatekeeper）

`.command` ファイルを初めてダブルクリックすると「開発元を確認できません」と出ることがある。
→ ファイルを**右クリック→「開く」→「開く」**で一度許可すれば、以降はダブルクリックで動く。

## launchd（自動実行）の管理コマンド

```bash
# 登録状況の確認
launchctl list | grep <label>

# 手動で今すぐ実行（動作テスト）
launchctl kickstart -k gui/$(id -u)/<label>

# 停止（解除）
launchctl bootout gui/$(id -u)/<label>

# 再登録
launchctl bootstrap gui/$(id -u) ~/Library/LaunchAgents/<label>.plist
```

- Macがスリープ中は実行されない。実行時刻はMacが起きている時間帯にする
- 実行結果は各フォルダの `自動実行ログ.txt` に残る

## トラブルシューティング

| 症状 | 原因 | 対処 |
|---|---|---|
| Discordに届かない / HTTP 403 | User-Agentヘッダー欠落 | テンプレートは対策済み。独自コードなら `"User-Agent": "Mozilla/5.0"` を追加 |
| HTTP 204 なのに届かない | 別チャンネルを見ている | Webhookを作ったチャンネルを確認 |
| ⚠️CSVから読めない | 列の並びが想定と違う / 別のCSVを入れた | サチコは `クエリ.csv`、GA4は「ページとスクリーン」のCSVかを確認 |
| 「初回取込」ばかり出る | 履歴.csvが毎回消えている | 履歴.csvは消さない運用と説明（テスト後のリセットは構築時だけ） |
| sitemapが見つからず0件 | 非標準構造 / sitemap無し | まず `competitor_watch.py check` で疎通確認。0件サイトは差し替え。無い場合はRSSや記事一覧ページの差分方式を検討 |
| ファイルは動くのにデータが溜まらない | フォルダの書き込み権限不足 | ツールフォルダ（履歴.csv・済み/を作る場所）に書き込み権限があるか確認。iCloud同期中のDesktop等で稀に発生 |
| AI改善案が出ない | キー未設定 / 無効 | `GEMINI_API_KEY` を確認。models エンドポイントで疎通確認 |
| 🚨課金アラートが来た | Gemini無料枠超過 | 頻度を下げる / 数日待つ / 課金検討。放置しても請求はされない |
| Gemini 503 | 一時的な混雑 | テンプレートは3回自動リトライ。頻発時は時間を置く |
| launchdが動かない | パス違い / 未登録 | `launchctl list` で確認、plist内のpython3パスを `which python3` と照合 |
